# 負荷テストツール

このプロジェクトは、Pythonで書かれたアプリケーションの負荷テストを行うためのツールです。
CPU、メモリ、I/Oの負荷をかけながら、対象プログラムのパフォーマンスを測定します。

## 機能

- CPU負荷テスト
- メモリ負荷テスト
- I/O負荷テスト
- リソース使用率のログ記録
- テスト結果の自動保存

## 必要条件

- Python 3.13以上
- psutil

## インストール

```bash
pip install -r requirements.txt
```

## 使用方法

1. `config/config.py`に必要な設定を記述（テンプレートから作成）
2. テスト対象のプログラムを用意
3. 以下のコマンドを実行：

```bash
python general_purpose_test.py
```

## ログ

テスト実行時のログは`test_log.txt`に保存されます。
ログには以下の情報が含まれます：
- CPU使用率
- メモリ使用率
- ディスク(I/O)使用率
- テスト開始・終了時刻
- エラー情報（発生時）
